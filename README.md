# Analog Finder

Find and characterize places on Earth that stand in for NASA's Moon Base and Mars sites, using open NASA data.
Pick a Moon or Mars target and the app ranks Earth sites by how well they match. For each site it shows,
with numbers, **where the analogy breaks down**, and it plans the **best 3-site test campaign**. It also
**checks itself**: established analogs must outscore ordinary places before we trust any new candidate.

Built as a starter kit for the NASA Space Apps Challenge 2026 challenge
*Identify Earth Locations that Analog the Permanent Moon Base Locations and Mars*.
The team plan (roles, timeline, demo script) lives in the shared plan doc.

---

## 1. See it running (2 minutes)

You need Python 3 (already on Mac/Linux; Windows: install from python.org and tick "Add to PATH").

```bash
cd analog-finder
python -m http.server 8000 --directory web
```

Open http://localhost:8000 in Chrome, Edge or Firefox. Stop the server with Ctrl+C.

No terminal? Double-click `web/index.html`. It still works; fonts need internet.

The map uses MapLibre (3D globe). If it can't load (no WebGL, blocked script), the app switches to a built-in
flat map automatically. Force the flat map with `?map=svg` at the end of the address.

## 2. Swap the seed numbers for real NASA data (10-20 minutes, needs internet)

The app ships with **seed estimates** (hand-entered, marked "estimate" in the app). Replace them:

```bash
python -m pip install -r pipeline/requirements.txt
python pipeline/build_dataset.py                 # NASA POWER climate + SRTM terrain for all 51 sites
python pipeline/build_dataset.py --with-modis    # optional: MODIS vegetation (slower)
python pipeline/build_dataset.py --with-geology  # optional: rock-type suggestions to review
```

Refresh the browser. The header dot turns green and every value shows its source.
Read `pipeline/build_report.md` to see each seed value next to the downloaded one, and sanity-check the big changes.
Downloads are cached in `pipeline/.cache/`, so re-runs are instant. If an API fails, that site keeps its seed value and the
script says why. Test one site first: `python pipeline/fetch_power.py 75.38 -89.67`.

## 4. Common edits

| I want to... | Do this |
|---|---|
| Add an Earth site | Add a row to `pipeline/earth_sites.csv`, then run `python pipeline/build_dataset.py --offline` (or without `--offline` to fetch data). |
| Add or fix a Moon/Mars target | Edit `web/data/targets.js`. Every target needs a source in `refs`. |
| Make a comparison stricter | Lower that feature's `sigma` in `web/js/config.js`. |
| Add a mission-test preset | Add an entry to `presets` in `web/js/config.js`. |
| Find brand-new candidates | `python pipeline/scan_region.py --name sahara --bbox 10,18,22,27`, then add `<script src="data/scan_cells.js"></script>` after `earth_sites.js` in `index.html`. |
| Link straight to a target | Add `#target-id` to the address, e.g. `http://localhost:8000/#mars-jezero`. |

## 5. Put it online (GitHub Pages)

1. Create a public GitHub repo and upload this folder (or `git push`).
2. Repo, then Settings, then Pages. Under "Build and deployment", choose **Deploy from a branch**, branch `main`, folder `/ (root)`. Save.
3. After about a minute your site is at `https://<user>.github.io/<repo>/`. The root `index.html` forwards to `web/`.

Space Apps requires a public repo link and an open-source license: this kit is MIT (see `LICENSE`).

## 6. Tests

```bash
node --test tests/scoring.test.js          # scoring maths + data checks (Node 18+)
python -m unittest discover -s tests       # pipeline with fake downloads (no internet needed)
```

Run both before every demo. If a data edit breaks something, the data checks say which site or target.

## 7. Troubleshooting

| Problem | Fix |
|---|---|
| "No data loaded" | Run `python pipeline/build_dataset.py --offline` to regenerate `web/data/earth_sites.js`. |
| Map is flat, Globe button disabled | MapLibre couldn't start (no WebGL or offline). Everything else still works. |
| `HTTP 429` from NASA POWER | You hit the rate limit. Wait a minute and re-run; finished sites come from the cache. |
| Terrain fails near the poles | Expected: web map tiles stop at 85 degrees. Those sites keep curated values. |
| NASA imagery button shows nothing | Needs internet; GIBS tiles cannot load inside sandboxed previews. |
